# Jogos PAC 4

Repositório com os jogos desenvolvidos pelas equipes do PAC 4.

## Como o repositório é organizado
Cada jogo tem a sua própria pasta, com o nome do jogo:

```
jogos-pac-4/
└── nome-do-jogo/
    ├── RESUMO_DO_JOGO.md   resumo do jogo + link da pesquisa de opinião
    ├── executavel/         o jogo pronto (.exe), sem código-fonte
    ├── documentacao/       GDD (Game Design Document)
    └── video/              vídeo do jogo
```
