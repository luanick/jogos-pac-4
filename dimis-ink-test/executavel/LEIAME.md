# Executável

O jogo (`Dimi.s.Ink.Test.exe`, cerca de 220 MB) é maior que o limite de 100 MB por arquivo do GitHub, por isso ele fica numa Release do repositório, e não dentro desta pasta.

👉 **[Baixar o Dimi's Ink Test (Release v1.0)](https://github.com/luanick/jogos-pac-4/releases/tag/dimis-ink-test-v1.0)**

Na página, procure a seção **Assets** e clique em `Dimi.s.Ink.Test.exe`. O GitHub troca o apóstrofo do nome por um ponto, então é normal o arquivo ter esse nome.

## ⚠️ Aviso: o Windows pode bloquear o jogo
Ao abrir, o Windows pode mostrar a tela azul **"O Windows protegeu o computador"** (SmartScreen), com "Fornecedor desconhecido". Isso acontece porque o jogo é um projeto de estudantes e não tem assinatura digital paga. O aviso aparece com qualquer programa novo e pouco conhecido, e não indica que há algo errado com o arquivo.

Para abrir o jogo:
1. Na tela azul, clique em **Mais informações**.
2. Clique no botão **Executar assim mesmo**.
3. O jogo abre em tela cheia. Use `Esc` para pausar.

Só faça isso se você baixou o arquivo desta página, do repositório oficial `luanick/jogos-pac-4`.

### Se o navegador bloquear o download
O Chrome e o Edge podem avisar que o arquivo "não é baixado com frequência". Clique nos três pontos (`⋯`) ao lado do arquivo na lista de downloads, depois em **Manter** e, se pedir, em **Manter mesmo assim**.
