# Léo na Amazônia

## O que é
Jogo educativo de plataforma. Em cada fase, Léo coleta pela selva as letras do nome de um animal da Amazônia, que estão fora de ordem. Depois, o jogador monta a palavra na ordem certa e aprende uma curiosidade sobre o animal. Cuidado com a onça, os buracos e o rio! O jogo faz parte do projeto **GramaVentura** (veja a documentação).

## Ficha do jogo
| | |
|---|---|
| **Gênero** | Plataforma 2D educativo |
| **Conteúdo** | Língua portuguesa: formação de palavras |
| **Engine** | Godot 4.7 |

## Controles
| Ação | Tecla |
|---|---|
| Andar | Setas ou A / D |
| Pular | Espaço, seta para cima ou W |
| Escolher no menu / continuar | Enter |
| Desfazer letra (montar a palavra) | Backspace |
| Voltar ao menu | Esc |
| Liga/desliga o som | M |

## Como jogar
1. Baixe o [`Leo-na-Amazonia.zip`](executavel/Leo-na-Amazonia.zip) (na página do arquivo, clique em **Download raw** ou no ícone de download).
2. Extraia o zip e abra `Léo na Amazônia.exe`. O arquivo `.pck` precisa ficar na mesma pasta.

## ⚠️ O Windows pode bloquear o jogo
Se aparecer a tela azul **"O Windows protegeu o computador"** (SmartScreen), é normal: o jogo é um projeto de estudantes e não tem assinatura digital paga. Clique em **Mais informações** e depois em **Executar assim mesmo**.
